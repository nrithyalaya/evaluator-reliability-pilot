# How to publish this repository on GitHub

This folder is prepared for GitHub, but is not published automatically.

1. Sign in at https://github.com/new .
2. Create a **Public** repository named `evaluator-reliability-pilot` (use another available name if taken). Do **not** initialize it with a README, license, or `.gitignore`, because those files are already included here.
3. Open the repository, select **Add file → Upload files**.
4. Drag the **contents of this extracted folder** into GitHub (not the ZIP file itself). Keep the nested folders (`data`, `results`, `notebooks`, `pilot`, `tests`). GitHub's file uploader supports folder drag-and-drop in browsers.
5. Commit the files. Open `README.md` to confirm it displays the results and limitations.
6. Copy the actual repository URL from the browser; only that published URL belongs in Anthropic's notable-work links field.

Example URL format: `https://github.com/<your-github-username>/evaluator-reliability-pilot` — illustrative, NOT a live link.

**Review before publishing:** Confirm that all research statements and code are accurate and that you understand the experimental procedure. Do not upload unpublished student videos, credentials, private business data, or personal application materials. If an application has attribution or disclosure rules, follow those requirements.
